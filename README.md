# 简历

简历是一个纯前端中文简历编辑器，内置 37 个模板入口，支持表单和 Markdown 双向编辑、A4 实时预览、PDF 导出和可编辑备份。简历与照片保存在浏览器里，排版和导出也在本机完成。

## 技术栈

| 模块 | 技术 |
| --- | --- |
| 界面与构建 | React 19、TypeScript、Vite |
| 编辑 | Tiptap 富文本、自定义 Markdown 解析与源码编辑 |
| 本地数据 | IndexedDB（idb），支持自动保存、历史版本和跨标签页冲突处理 |
| PDF 与图片 | React PDF 在 Web Worker 中生成 PDF，PDF.js 渲染同一份文件，支持逐页导出 PNG |
| 备份与离线 | fflate 打包 ZIP，vite-plugin-pwa 和 Workbox 缓存应用、模板及本地中文字体 |
| 测试 | Vitest、jsdom、fake-indexeddb |

## 本地运行

使用 Node.js 22.13+（22.x）或 24 LTS。在项目目录执行：

```sh
npm ci
npm run dev
```

开发页面为 `http://127.0.0.1:5173/`。要测试离线体验，使用生产构建预览：

```sh
npm test
npm run build
npm run preview
```

构建产物位于 `dist/`，预览地址为 `http://127.0.0.1:4173/`。首次访问需加载离线资源，看到「已可离线使用」后可离线打开、编辑和导出。

## 使用方法

1. **创建简历**。从「简历模板」选一个样式，选择示例或空白内容，再选择「用表单编辑」或「用 Markdown 编辑」。已有简历可在编辑器顶栏切换两种方式，继续使用当前模板。
2. **填写与排版**。按模块编辑个人信息和经历，上传本地头像，再用「模板风格」或「排版设置」调整配色、字号、行距和边距。看到「已保存」后即可关闭页面。
3. **导出**。右上角「导出」下载预览对应的 PDF。下拉菜单还可导出 ZIP 打包的逐页 PNG、Markdown 源文件或可编辑备份。
4. **迁移或恢复**。在「我的简历」下载单份可编辑备份，或点「备份全部」。在另一设备或浏览器使用「导入恢复」导入 `.resume.zip`，即可继续编辑原内容和排版。已有 Markdown 文件也可从首页导入。

浏览器按协议、域名和端口隔离数据。更换浏览器、设备或部署地址前，请先备份。清除站点数据会删除本机简历及离线缓存。需要日后修改的简历请保留 `.resume.zip`。

## 静态部署

执行 `npm ci` 和 `npm run build`，将 `dist/` 发布到 HTTPS 静态托管。站点采用 Hash 路由，支持部署在根目录或带末尾斜杠的子目录。缓存配置可参考 `deploy/nginx.conf` 或 `public/_headers`，其中 `index.html`、`sw.js` 和 `manifest.webmanifest` 应允许浏览器及时检查更新，带内容哈希的资源可长期缓存。服务器应为 `.js` 和 `.mjs` 返回 JavaScript MIME 类型。

## 项目结构

| 路径 | 内容 |
| --- | --- |
| `src/components/` | 编辑器、模板库和交互组件 |
| `src/lib/` | 本地存储、Markdown、备份与图片处理 |
| `src/pdf/` | 模板排版、PDF 生成与预览 |
| `public/` | 模板封面、图标、本地字体及许可证 |
| `tests/`、`scripts/` | 自动化测试和维护脚本 |
